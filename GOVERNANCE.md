# Governance

The initial maintainer is `@flemingw`. Substantial design decisions are reviewed
through pull requests and recorded in the architecture documentation.

The protocol is nonprofit-neutral and agent-neutral. Adapter inclusion is not
charity verification, endorsement or agent-platform approval. Each adopting host
controls which providers it enables and is responsible for its deployment.

Repository visibility, releases and ownership transfers require the owner's
approval. Packages remain private during foundation review. Before public
release, establish monitored private security reporting, release ownership and
a version-support policy. No affiliation or future organizational transfer is
assumed.
