# Security

This is foundation-review software, not an approved production giving deployment.
Examples use synthetic data and accept no payment. Production payment, donor data
and agent-platform compatibility require separate provider/host review.

Report suspected vulnerabilities through [a private GitHub security advisory](https://github.com/flemingw/open-giving-sdk/security/advisories/new).
Do not put credentials, donor information, or private case content in issues,
pull requests, or Actions logs.

A production support or response-time commitment has not been established.
